# 分析成功后自动创建报告设计

## 目标

一次测量的分析结果成功入库后，报告列表应立即具备该测量对应的报告记录，不再要求用户先点击“生成报告”或“报告预览”。

## 行为规则

1. 仅在分析结果保存成功、测量记录更新为“已完成”后创建报告。
2. 报告以 `MeasurementId` 唯一关联测量；已有报告时直接复用，不重复插入。
3. 新报告状态为可查看，标题、患者、操作员和分析结果关联沿用现有报告生成规则。
4. 报告创建失败时记录错误日志，但不把已成功的分析和测量状态改为失败。
5. 原有“生成报告”和“报告预览”入口继续调用幂等的获取或创建逻辑，行为保持兼容。
6. 报告模块现有筛选规则不变：只显示测量已完成且分析结果成功的报告。

## 实现边界

- 在分析完成流程中调用报告服务，不在算法服务或数据库实体层引入 UI 逻辑。
- 抽取一个可单元测试的分析完成报告创建协调器，负责幂等调用和异常隔离。
- 不改变报告预览、导出、打印和列表布局。

## 验证

1. 分析保存成功后创建报告。
2. 同一测量重复调用不会产生第二条报告。
3. 报告创建异常不会向分析完成流程抛出。
4. 完整测试和 Debug 构建通过。
