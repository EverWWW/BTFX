# 数据安全与流程一致性优化设计

## 范围

本轮处理以下内容：

1. 数据库初始化防误删。
2. SQLite WAL 模式下的可靠备份与恢复。
3. 重新分析后报告关联最新分析结果。
4. 分析完成时测量状态和报告记录的一致性。
5. 剩余中文硬编码、乱码和安装包冗余。

在线更新和软件激活安全不在本轮修改范围内。

## 1. 数据库初始化

- 已存在数据库初始化失败时，程序不得删除或重建数据库。
- 失败后将主数据库、`-wal`、`-shm` 文件复制到 `Data/Recovery/<timestamp>/`，记录日志并终止启动。
- 只有数据库文件原本不存在时才允许创建全新数据库。
- `PRAGMA user_version` 读取失败必须抛出异常，不能按版本 0 处理。
- 移除依赖强制 GC 释放 SQLite 文件锁的逻辑。

## 2. 备份与恢复

- 备份使用 SQLite `BackupDatabase` 在线备份接口生成一致的数据库快照，不直接复制 WAL 模式下的主文件。
- 快照生成后执行 `PRAGMA integrity_check`，只有结果为 `ok` 才打包。
- 配置 JSON 继续包含在备份包中。
- 恢复时先解压到临时目录并校验数据库完整性和结构版本。
- 校验成功后写入待恢复数据库和恢复标记；当前进程不覆盖正在使用的数据库。
- 下次启动、数据库初始化之前执行原子替换，同时将旧数据库保存到 `Data/Recovery/`。替换失败时恢复旧文件并终止启动。
- 自动备份回调在服务释放后不得重新启动定时器，并防止手动备份与自动备份并发执行。

## 3. 分析完成与报告一致性

- 分析结果子表保存成功后，使用一个数据库事务完成：
  - 测量状态更新为 `Completed`；
  - 按 `MeasurementId` 获取或创建报告；
  - 报告的 `AnalysisResultId` 更新为本次新结果 ID；
  - 报告状态更新为可查看。
- 报告表为 `MeasurementId` 增加唯一索引。
- 数据库升级到 v8 时清理历史重复报告：保留更新时间最新的一条，再创建唯一索引。
- 应用启动时执行一次轻量一致性修复：成功分析结果存在时，将对应测量状态和报告关联修复到最新结果。
- 报告加载仍允许按指定 `AnalysisResultId` 读取快照；重新分析完成时由收尾事务显式切换到最新结果。

## 4. 本地化与文本

- `MeasurementWorkflowResumeService` 不再返回硬编码中文，改为稳定状态码，由 ViewModel 使用本地化资源生成操作文字和说明。
- 修复相机预览日志中的乱码文本。
- 修正仍显示 `123456` 的默认密码提示为当前默认密码 `688626`，若该资源未被使用则删除。
- 中英文资源键继续保持一一对应。

## 5. 发布与安装

- 不再复制未使用的 `ffplay.exe`，减少约 98 MB 发布体积。
- `report-reference-ranges.json` 在升级安装时不得覆盖用户已修改文件；仅首次安装时写入默认配置。
- 安装说明补充大恒 Galaxy SDK 和算法 `_internal` 目录为外部部署依赖。
- GPU `_internal` 仍不进入安装包。

## 失败处理

- 任何数据库恢复、迁移、完整性校验失败都保留原文件，不自动清空用户数据。
- 分析收尾事务失败时保留已保存的分析结果，记录明确错误；启动一致性修复负责后续恢复。
- 备份失败不得生成可见的半成品 ZIP。

## 验证

- 数据库初始化失败不会删除原数据库。
- WAL 中存在未检查点数据时，备份恢复后数据完整。
- 损坏备份无法进入待恢复状态。
- 同一测量重新分析后报告指向最新分析结果，且报告始终只有一条。
- 中英文资源键一致，源码不再包含已知乱码。
- 完整测试、Debug 构建和 Release 发布通过。
