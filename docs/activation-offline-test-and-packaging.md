# 离线激活闭环测试与打包策略

## 测试闭环

1. 在未激活电脑启动主程序，进入软件激活页。
2. 点击“复制设备信息”，得到软件名称、产品型号、CPU 编号、硬盘信息、BIOS 编号、机器码。
3. 在内部电脑运行 `ActivationCodeTool.exe`。
4. 点击“粘贴设备信息”，确认字段自动填入。
5. 点击“生成激活码”，复制生成结果。
6. 回到未激活电脑，在激活页填写激活码，点击“离线激活”。
7. 激活成功后重启主程序，确认直接进入登录页。

## 授权文件位置

主程序离线激活成功后，授权文件保存到：

`%AppData%\BTFX\License\XY-K-BTFX-I.lic`

该目录不在安装目录内，重装软件时默认不会被安装包覆盖或删除。

## 打包策略

客户安装包只包含主程序，不包含内部激活码生成工具。

内部激活码生成工具单独发布，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\ActivationCodeTool\publish-tool.ps1
```

输出目录：

`publish\internal-tools\ActivationCodeTool`

该目录可以交给内部运维或测试人员使用，不建议放入客户安装包。

## 注意事项

- 离线激活码与目标电脑硬件信息绑定，换电脑后需要重新生成。
- 产品型号固定为 `XY-K-BTFX-I`。
- 产品编号仅在线激活必填；离线激活码当前只按设备信息计算。
- 若硬盘、主板或 CPU 信息发生变化，原授权可能失效。
